# 🏥 Care Companion - แอปพลิเคชันผู้ช่วยดูแลผู้ป่วยและผู้สูงอายุ

แอปพลิเคชันจำลองระบบการจองผู้ดูแล ค้นหา นัดหมาย สนทนา และให้คะแนนการบริการ

## 📸 Preview
![App Preview](ใส่ลิงก์รูปภาพหรือลากรูปวางตรงนี้)

## ✨ Features
* 🔍 **Search & Filter:** ค้นหาผู้ดูแลตามสถานที่และช่วงเวลา
* 📅 **Booking System:** ระบบจองบริการและคำนวณราคายอดรวมอัตโนมัติ
* 💳 **Payment Simulation:** จ่ายเงินผ่าน QR Code พร้อมแนบหลักฐานสลิป
* 💬 **Real-time Chat Simulation:** สนทนากับผู้ช่วย พร้อมระบบจำลองการพิมพ์ตอบกลับ
* ⭐ **Review System:** ให้คะแนนและรีวิวหลังจบงาน
* 📜 **History:** บันทึกประวัติการจอง ย้อนดูและแชตต่อได้
