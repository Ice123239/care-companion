# 🏥 Care Companion (แคร์ คอมพาเนียน)

แอปพลิเคชันจำลองระบบการจองผู้ดูแล ค้นหา นัดหมาย สนทนา และให้คะแนนการบริการสำหรับผู้ป่วย/ผู้สูงอายุ

## 📸 หน้าตาแอปพลิเคชัน (Preview)

![App Preview](https://github.com/user-attachments/assets/...)

## ✨ ฟีเจอร์หลัก (Key Features)
* 🔍 **ค้นหาผู้ดูแล:** ค้นหาและคัดกรองผู้ดูแลตามสถานที่ เวลา และราคา
* 📅 **นัดหมาย & ชำระเงิน:** ระบบจองพร้อมจำลองการชำระเงินผ่าน QR Code และแนบสลิป
* 💬 **ระบบแชตจำลอง:** สนทนากับผู้ช่วย พร้อมการพิมพ์ตอบกลับอัตโนมัติ (Simulation)
* ⭐ **ระบบรีวิว:** ให้คะแนนและเขียนรีวิวหลังจบงาน
* 📜 **ประวัติการจอง:** บันทึกประวัติลง LocalStorage สามารถกลับมาดูหรือแชตต่อได้
* 🔑 **Mockup Login:** จำลองระบบเข้าสู่ระบบเพื่อความสมบูรณ์ของ User Flow

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **State/Storage:** React State & LocalStorage
